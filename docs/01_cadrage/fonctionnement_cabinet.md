# Fonctionnement du cabinet medical

## Avant la consultation

- Le patient arrive avec rendez-vous ou en urgence.
- La secretaire ou le medecin recherche le dossier du patient.
- Dans la solution cible, le dossier est accessible dans la base de donnees.

## Pendant la consultation

- Le medecin consulte l'historique.
- Le medecin saisit la visite.
- Le medecin peut creer une ordonnance.
- Le medecin peut demander des analyses.

## Apres la consultation

- Les resultats d'analyses sont rattaches au dossier patient.
- Les informations sont consultables par le medecin traitant et, si necessaire, par les autres medecins du cabinet.
