# Choix de modelisation objet-relationnelle

## Objectif

Representer certains concepts medicaux sous forme de types objets, collections ou references.

## Pistes de modelisation

- Type `Patient`.
- Type `Medecin`.
- Type `Medicament`.
- Type `Posologie`.
- Type `LigneOrdonnance`.
- Collection de lignes d'ordonnance.
- Table objet pour les patients, medecins, visites et ordonnances.
