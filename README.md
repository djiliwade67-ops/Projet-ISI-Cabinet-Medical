# Projet SQL - Cabinet Medical

Projet du module Bases de Donnees, annee academique 2025-2026.

Date limite de remise : 08/07/2026 avant 00h00.

## Objectif

Proposer deux solutions d'informatisation du dossier medical :

1. Une solution relationnelle.
2. Une solution objet-relationnelle.

## Structure du projet

- `docs/00_reference` : sujet officiel.
- `docs/01_cadrage` : exigences et description generale.
- `docs/02_securite` : confidentialite, utilisateurs et droits.
- `docs/03_relationnel` : modele conceptuel, dictionnaire et schema relationnel.
- `docs/04_objet_relationnel` : modele et schema objet-relationnel.
- `docs/05_livrable` : dossier final Word/PDF.
- `src/relational` : scripts SQL relationnels.
- `src/object-relational` : scripts SQL objet-relationnels.
- `tests` : scripts de validation.
- `project-management` : planning, roles et suivi GitHub Projects.
